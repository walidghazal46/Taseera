# Taseera

Taseera is a mobile-style React application for construction pricing, supplier management, and company/project tracking.

## Features

- Arabic-first mobile UI with bottom navigation
- Companies directory with project organization
- Pricing workspace for construction items and market comparison
- Supplier directory with categorized filtering
- Settings, language, theme, and account flows
- Guest mode and login screen experience

## Tech Stack

- React
- Tailwind CSS
- Create React App

## Run Locally

```bash
npm install
npm start
```

## Production Build

```bash
npm run build
```

## Notes

- The app currently uses local sample data and imported workbook-derived pricing data.
- Some admin and review workflows are partially scaffolded for future expansion.
